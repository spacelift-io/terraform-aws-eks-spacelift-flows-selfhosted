# Terraform AWS EKS Spacelift Flows Self-hosted

> [!WARNING]
> This module is deprecated and no longer maintained.

Spacelift Flows is now deployed by the same module as Spacelift Deploy: [terraform-aws-eks-spacelift-selfhosted](https://github.com/spacelift-io/terraform-aws-eks-spacelift-selfhosted). It runs Flows on the cluster, database and network that module already creates, so there is no second environment to manage.

To get started, see the [with-flows example](https://github.com/spacelift-io/terraform-aws-eks-spacelift-selfhosted/tree/main/examples/with-flows).
